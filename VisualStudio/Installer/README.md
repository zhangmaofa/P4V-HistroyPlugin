# P4 Histroy Plugin 安装包

当前安装包：`P4HistroyPlugin.vsix`

- 版本：`0.1.7`
- 适用环境：Visual Studio 2022（17.x）、Windows
- SHA-256：`024E5BA11E1B089B5CF39AEA315A6259A064AE2B898E0112F7B36756803B5E8E`

## 安装

1. 关闭所有 Visual Studio 实例。
2. 双击 `P4HistroyPlugin.vsix`。
3. 在 VSIX Installer 中选择需要安装的 Visual Studio 2022 实例并完成安装。
4. 重新启动 Visual Studio，打开已纳入 P4 的文本文件。

如果机器上仍安装着旧版 `P4 Line Lens`，请先卸载旧版，避免两个扩展同时加载。
