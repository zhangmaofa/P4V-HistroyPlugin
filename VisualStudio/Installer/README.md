# P4 Histroy Plugin 安装包

当前安装包：`P4HistroyPlugin.vsix`

- 版本：`0.1.8`
- 适用环境：Visual Studio 2022、Visual Studio 2026、Windows
- SHA-256：`B7C28CBD4F393A7BF13E3988CC28D0136FB41CD5E64D26C40CD3A1FB3EF3999B`

## 安装

1. 关闭所有 Visual Studio 实例。
2. 双击 `P4HistroyPlugin.vsix`。
3. 在 VSIX Installer 中选择需要安装的 Visual Studio 2022 或 Visual Studio 2026 实例并完成安装。
4. 重新启动 Visual Studio，打开已纳入 P4 的文本文件。

如果机器上仍安装着旧版 `P4 Line Lens`，请先卸载旧版，避免两个扩展同时加载。
